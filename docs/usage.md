# 用法

中文 | [English](usage.en.md) · [返回 README](../README.md)

## 看一个视频或录音

```text
用 watch-for-me 帮我看完这个录音，整理成双语对照全文，再理出里面的 feedback、决定和待办：<文件路径>
```

各 agent 指定 skill 的写法不同，比如 Claude Code 是 `/watch-for-me:watch-for-me`，Codex 是 `$watch-for-me`。

把 `<文件路径>` 换成本地音频或视频的路径，也可以换成在线视频链接。讲座可以要一份学习指南；操作演示可以要步骤和检查结果的方法。

`watch-for-me` 先做全文（Media Reader），再写笔记（Media Notes）。它也能从已有的原文底稿（Media Source Map）或输出文件夹（Media Bundle）接着做，不必重新转写。

## 说话人

如果知道实际有几个人说话，在请求里写上人数。也可以给一个范围、名字或身份。不写人数时，模型会自己估计有几种声音。agent 会把这些信息和对话内容、你提供的身份线索放在一起判断谁在说话，也就是说话人识别（Speaker Attribution）。混在一起的声音它分不开；两个人同时说话时，也不保证两句话都能还原。

想改说话人的名字，在阅读页上点名字旁边的铅笔。新名字会在整页预览；点复制按钮，把生成的 prompt 粘贴给 agent，它会更新原文底稿并重新渲染。页面本身不会写文件。

## 追问和摘录

想接着问，指向已有的输出文件夹，直接提问题，或者说清楚要摘哪一段。agent 会用现成的内容和原文位置回答，不会重建整个输出文件夹。
