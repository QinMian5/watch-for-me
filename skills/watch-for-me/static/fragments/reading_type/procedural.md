# Procedural material

Organize the Notes around the goal-to-result chain:

```text
goal and prerequisites
→ ordered actions
→ visible state changes
→ checks and corrections
→ final result
```

- Preserve action order, dependencies between steps, and the reason each consequential action is taken.
- Record commands, settings, materials, warnings, and observable success states that change execution.
- Use the minimum frame sequence that makes each important state transition understandable.
- Separate required steps from optional refinements through the source's own framing.
- Explain the procedure with enough context for a reader to reproduce the essential result from the Notes.
