# Visual evidence

## Find qualifying visual units

Read all Source Blocks and review the full video. Use slide or scene changes, representative frame batches, and focused inspection around related blocks.

A visual unit qualifies when its visible form preserves information absent from speech or makes structure, relationships, comparison, state, or action materially easier to understand.

Match review to reading type:

- expository: readable slides, diagrams, charts, tables, and materially changing board states
- procedural: the minimum sequence showing each necessary action or state transition
- dialogic: displayed material that clarifies the discussion
- reportorial: visible event evidence, maps, data, source identities, and contributing scenes
- reflective: displayed material or scenes the reflection refers to

## Extract representative frames

- choose a complete, readable state from each qualifying unit
- use one frame for a stable visual and the minimum sequence when changing states affect understanding
- keep materially distinct diagrams, charts, tables, demonstrations, interfaces, objects, or scenes
- use the smallest set covering every qualifying visual unit

List each frame's timestamp and related `S...` blocks in `structure.json`, in timeline order, as `references/assembly.md` describes. The script assigns `F...` IDs and `assets/frames/` paths; save each extracted frame at its path under `MEDIA_DIR`.

The shared map establishes evidence relationships. The Reader can render the complete qualifying set; the Notes can select the subset that supports its compact synthesis.
